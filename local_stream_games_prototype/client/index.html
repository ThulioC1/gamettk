como a live controla o jogo

O tiktok/bot.py lê a live e repassa cada comentário, presente, like e follow como evento para o servidor, que entrega ao módulo do jogo (server/games/). O navegador só desenha o estado — quem decide é o servidor.

Sem live? python3 simulator/simulator.py simula comentários e presentes pelo terminal, ou --auto para gerar movimento sozinha.

Fechar navegador não derruba o jogo: o estado vive no servidor. Para trocar de jogo, use o seletor acima ou /?game=corrida.
